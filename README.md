Sobre o projeto:
Página web com tema Pokédex, construída em HTML/CSS puro, com dados de pokémons gerados via script Node.js e exibidos em cartas.

Funcionalidades:

- Header com botão de mais opções, título centralizado, ícone de mensagens e perfil;
- Navbar de navegação;
- Layout com sticky footer;
- Exibição de pokémons em cartas (grid) a partir de um JSON gerado via Node.js;
- Protótipo completo no Balsamiq: tela padrão, favoritos, login, perfil, sobre, tela de pokémon individual, erro 404 e pop-up de comparação de pokémons;

Wireframes:
Protótipo de baixa fidelidade feito no Balsamiq, cobrindo todas as telas principais do fluxo do usuário.

Estrutura:

- `pokemons.json` — dados dos pokémons (número, nome), gerado via script Node.js;
- `assets/` — imagens de fundo e banner;
